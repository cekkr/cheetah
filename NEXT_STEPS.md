# To do:
- **Fix the prefix-overlap trie defects (highest priority — data loss).** Three confirmed defects, all predating the adaptive container and reproducing on both strides; reproduced by the skipped `TestPreexistingJumpTerminalDefects` in `pair_adaptive_test.go`:
  1. Storing a key that is a strict prefix of an existing key fails outright (`offset beyond key length` from `nextChunk` at `offset == len(key)`), so a prefix-free key set is currently a hard requirement.
  2. `lookupPairAt` checks `entryHasJump` before the entry's own terminal, so a key ending on an entry that carries both a terminal and a jump is reported missing even though `PAIR_SCAN` returns it.
  3. Deleting one of two prefix-sharing keys drops its sibling (`promoteChildToJump` / `collectSingleBranchPath` collapse a node that still holds a live terminal).
- **Fix the `PAIR_SUMMARY` deadlock (server hang).** `walkPairSummary` enqueues child tasks with a blocking send into a `workers*4` (~32 slot) channel; once it fills, every worker blocks sending and the command hangs forever at 0% CPU (reproduced on a 20k-key trie, both strides). `walkPairTable` already solves this with its `enqueue` helper (`select` + `default` → process the task inline); apply the same pattern to the summary walk and add a regression test that summarises a trie larger than the queue.
- **Make cursor pagination deterministic.** A full paginated `PAIR_SCAN` past the first page loses entries and varies run to run on identical data (12k keys → 11,727 / 11,727 / 11,726 / 11,705), because parallel collection races the limit/abort and the derived cursor. Single-page scans are stable; `PAIR_SUMMARY` is the reliable full traversal today.
- **Optional: per-node stride widening.** The adaptive container already removes the memory cost of a wide stride. The remaining half of "dynamic indexing" is letting an individual hot node widen its stride (1 → 2 bytes) to halve subtree depth, which requires re-chunking that node's children and jump segments — high regression risk in the trie mutation paths, so it was deliberately deferred.
